# 日本語入力の点検表

Compose への移行の段階 0（試作）と、段階 5 のリリース前点検で使う。設計は `docs/plan/kmp-migration-design.md`。

## 合格条件にする環境

- macOS: 標準の日本語入力、ライブ変換オン（既定）、ローマ字入力
- Windows: 11、新しい Microsoft IME（既定）

ほかの設定（macOS のライブ変換オフ・かな入力、Windows 10、以前のバージョンの Microsoft IME）でも試せたら「ほかの環境」の欄に書く。合否には入れない。

## 項目

手順の「→」は、キーを1つずつ順に押すこと。特に書いていなければ、日本語入力はオン（ひらがな）で、ローマ字で打つ。

| 項目 | 手順 | 期待 |
|---|---|---|
| 1. 変換中の表示 | 空の行で `n` `i` `h` `o` `n` `g` `o` → スペース | 「にほんご」が行の中に下線つきで出る。スペースで出る候補窓が、文字のすぐ近くに出る（画面の左上などに飛ばない）。2 行目以降の空の行でも同じ |
| 2. 確定の Enter | 空の行で `k` `a` `n` `j` `i` → スペース → Enter → もう一度 Enter | 1 回目の Enter で「漢字」が確定し、新しい行はできない。2 回目の Enter で新しい行ができる |
| 3. スラッシュコマンド | (a) 英数で `/` → 日本語入力に切り替え → `m` `i` → スペース → 「見」で Enter<br>(b) 日本語入力のまま `/` キー（「／」が出る）→ 必要なら Enter で確定 | (a) `/` でメニューが出て、「見」の確定で見出し 1〜3 に絞られる。確定の Enter でメニューの項目が選ばれたり、行が分かれたりしない<br>(b) 「／」でもメニューが出る |
| 4. 全角の記号 | (a) 日本語入力のまま `[` `[`（「「」が2つ）→ 必要なら Enter で確定<br>(b) 行の先頭で、日本語入力のまま `#` → スペース（「＃　」）→ 必要なら Enter で確定 | (a) ページへのリンクの候補が出る<br>(b) 行が見出し 1 に変わる。確定の Enter で行が分かれない |
| 5. 文字の欠け・行の分かれ | (a) 文字のある行の途中で `t` `o` `u` `k` `y` `o` `u` → スペース → Enter<br>(b) 空の行で `k` `y` `o` `u` `h` `a` `i` `i` `t` `e` `n` `k` `i` `d` `e` `s` `u` → スペース → Enter | (a)(b) とも、確定した文字がすべて入る（先頭が欠けない）。1 行のまま（行が分かれない） |
| 6. 装飾の上での入力 | 「あいうえお」の「いう」を選んで Cmd/Ctrl+B → 「う」の後ろで `k` `a` → スペース → Enter | 「いう」の太字の表示が、変換中も確定後も崩れない |
| 7. 行の移動・削除・分割 | (a) 3 行書いて、↑↓ で行を移る<br>(b) 空の行で Backspace<br>(c) 「あいうえお」の「う」の前で Enter | (a) 前後の行に移る<br>(b) 行が消えて、前の行の末尾に移る<br>(c) 「あい」と「うえお」の 2 行に分かれる |
| A. 今の版で確定時に改行される手順 | （今の版で見つけた手順を書く） | 改行されない |
| B. 今の版でスラッシュコマンドがおかしくなる手順 | （今の版で見つけた手順を書く） | 手順の中で、何が正しい動きかも書く |

A・B の手順が分からないときは、1〜7 を打つ中で × になった手順を A・B に写す。
