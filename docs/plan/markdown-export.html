書き方は下の質問で決める。

ページ名と日付を、ファイルの先頭にどう書きますか？

MarkdownWriter.write() は、1ブロックを種類ごとの記号で書く。

畳んだ行の中身も全部書く。 BlockOps.listNumber() を使う。

字下げした行は、親のリスト項目の文字の位置にそろえる。

CommonMark の入れ子の決まり。 段落が前の行とつながらないため。 空白4つはコードになるため。 貼り直し PasteParser は空白2つを1段と読む。3段より深い番号付きリストは、貼り直すと段がずれることがある。

入れ子の装飾は、開いた順と逆の順で閉じる。

形はテストで決める。 日本語と強調 **「太字」**の のように記号と文字が並ぶと、CommonMark は太字と読まない。今回は直さない。

本文の中の Markdown の記号は、\ を付けて守る。

コードブロックとインラインコードはそのまま。

本文の中の * や # に \ を付けますか？

子ページごと書き出すと、フォルダの中に1ページ1ファイルで並ぶ。

どの範囲を書き出せるようにしますか？
全ページは「DearNotes 2026-10-11」フォルダに書く。日記は「デイリー」フォルダに入れる。

ファイル名はページ名から作り、使えない文字を _ に替える。

パスの長さの上限を越えないため。

ExportTree.write() は新しいフォルダを作り、ファイルを上書きしない。

途中で失敗したとき 書けたファイルは残す。メッセージに、書けたページの数とエラーを出す。

Shared: 新しいパッケージ app.dearnotes.export。UI に依存しない。

Not changing: DB、自動保存、貼り付け、Markdown の読み込み。
