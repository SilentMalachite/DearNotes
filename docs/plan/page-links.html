DearNotes のページ間リンク

Why · 2 requests フォルダ内リンクや他文書内リンクには対応してますか？ ベージ間リンクを設計してください

ユーザーは [[ を打って、ほかのページへのリンクを入れられる。

日本語入力のままでも使える。 ↑↓ で選び、Esc で閉じる。

候補にない名前のとき、新しいページを作れるようにしますか？

[[ か 「「 の後ろの文字で、ページ名を絞り込む。

「/」の候補と同じ扱い。

候補を選ぶと、[[語句 がページ名に替わり、PAGE の印が付く。

リンク先の名前を変えたとき、リンクの文字はどうしますか？
開いているページ 書き換えるページを開いているときは、PageEditor の行も読み直す。AutoSaver の書きかけと競合しないよう、先に保存する。

PageEditor.java:515 · insertPageLink()

onEdited() が marks を読み、AutoSaver に渡す。

リンクの末尾で続けて打った文字は、リンクに入らない。

そのままだと、打った文字もリンクになる。 リンクの文字を直すときは、印を残す。

Cmd/Ctrl を押しながらリンクを押すと、そのページへ移る。

MainWindow.open() を使う。

BlockView は PAGE の印を押すと、ページの id を MainWindow に渡す。

このページへのリンクの一覧を作りますか？

BlockRepo.linksTo() は marks の JSON を LIKE で探す。表は足さない。

数万行までは問題ない。遅ければ表を足す。

子ページごと書き出すと、ページ間リンクは相対パスのリンクになる。

書き出したファイルで、ページ間リンクをどう書きますか？

ExportTree は先に全ページのパスを決めて、それから書く。

Inline は PAGE の印を、パスがあればリンクに、なければ文字にする。

いつも文字だけになる。 「京都 (2).md」も開ける。

Shared: Mark にリンク先の id を足す。marks の JSON は4つ目に id を持つ。

Not changing: DB の表、URL のリンク、検索、貼り付け。

  • DB の表とマイグレーションは変えない。リンクは今の marks 列に入る。
  • URL のリンク（Cmd/Ctrl+Shift+L）は今のまま。
  • 検索はリンクの文字を、ふだんの文字として見つける。
  • 貼り付けた [[京都]] や [a](b.md) は、リンクにしない。
  • パソコンのファイルやフォルダへのリンクは作らない。
