DearNotes：Java 25 のメモアプリ新規作成

Why · 1 request Java25以上とSQLiteを使って、Notionのような日常的に使えるメモアプリを作成してください。macとWindows対応でjpackageをつかって配布したいです。

ユーザーは Notion と同じくブロック単位で書く。

文字を足すと候補が絞られる。 右の記号を行頭に打つと同じ結果になる。

エディタ部分は何で作りますか？
WebView は javafx.web を同梱する。インストーラーは約 60MB 大きくなる。

ブロックは1つの record で、種類は10個ある。

作成順に並ぶので索引が散らばらない。

行頭の「/」や「# 」でブロックの種類が変わる。

MarkdownShortcuts.java:8 · match()

Enter で次のブロックを作り、空の行で Backspace を押すと消える。

ドラッグで順番を変えると、1行の sort_key だけが変わる。

ページはサイドバーで入れ子になり、「今日」で日記を開く。

なければ作る。

サイドバーは parent_id からページの木を作る。

「今日」は今日のページを開き、なければ作る。

削除したページはゴミ箱に入り、30日後に消える。

アプリは変更を自動で保存する。保存ボタンはない。

1本の書き込みスレッドが、500ms ごとに変更をまとめて書く。

AutoSaver.java:50 · flushNow()

SQLite は WAL モードで開き、外部キーを有効にする。

ウィンドウを閉じると、未保存の変更を書いてから終わる。

Cmd/Ctrl+K で、日本語の語句から全ページを探せる。

FTS5 の trigram で、日本語の部分一致を探す。

unicode61 は日本語を語に分けられない。

2文字以下の語は trigram で探せないので LIKE を使う。

ユーザーは Mac で .dmg、Windows で .msi から入れる。

インストーラーに署名しますか？
macOS 15 以降は右クリックで開けない。「システム設定 › プライバシーとセキュリティ」で許可する。README に手順を書く。

Gradle が jlink で小さい JRE を作り、jpackage で包む。

JavaFX 入りの JDK が要る。 sqlite-jdbc と JavaFX はネイティブを読む。 新しい版が古い版を置き換える。

ビルドツールはどちらにしますか？

 開発機と CI は BellSoft Liberica Full JDK 25 を使う。JavaFX の jmods が最初から入っている。

jpackage は他の OS 向けに作れないので、CI が各 OS で作る。

データは OS のユーザーフォルダに置くので、更新しても消えない。

共有: pages と blocks の2つのテーブル。

ページの本文はどう保存しますか？

v1 に入れないもの: 同期、画像、共有、Linux 版。

  • クラウド同期と複数端末。DB は1台の1ファイルだけ。
  • 画像とファイルの添付。テキストのブロックだけ。
  • 他の人との共有、コメント、権限。
  • 表、カンバン、データベース型のページ。
  • 自動アップデート。新しい版はインストーラーで上書きする。
  • Linux 向けパッケージ。コードは動くが、配布物は作らない。
