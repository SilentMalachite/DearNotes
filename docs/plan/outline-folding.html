ユーザーは子の行を持つ項目を畳み、字下げした子の行を隠せる。

どの行を畳めるようにしますか？
表の作り直し blocks の CHECK 制約は ALTER で変えられない。v2 で blocks を作り直し、FTS のトリガーも作り直す。

項目の範囲は、字下げの深い行が続くところまでとする。

子をなくした行は、畳んだ印を自分で外す。

畳んだ状態は、ページを開き直しても残る。

畳んだ状態をどこに覚えますか？
PageEditor が畳んだ行の id を Set で覚える。ページを移るか終了すると、全部開く。

Block は collapsed を持つ。

BlockRepo は collapsed を読み、書く。

ps.setXxx(9…11) も直す。

キー操作と並べ替えは、隠れた行を壊さない。

新しい行は、隠れた 3 行の後に入る。

Enter と矢印キーは、隠れた行を飛ばす。

畳んだ行を動かすと、隠れた行も一緒に動く。

隠れた行に触れる操作は、先にその節を開く。

Shared: 範囲と目次を計算する Outline。UI から切り離してテストする。

Not changing: サイドバーのページ一覧、検索、貼り付けの解析、番号の付け方。

  • サイドバーのページ一覧は、今も TreeView で畳める。変えない。
  • SearchRepo と FTS は変えない。検索は隠れた行も見つける。
  • PasteParser は変えない。貼った行は開いた状態で入る。
  • 番号付きリストは、隠れた行も今と同じく数える。
  • ブロックの種類は足さない（「トグル」を選んだときを除く）。
